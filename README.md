# Dr. Maya Reynolds Therapy Website

A responsive therapist website designed for Dr. Maya Reynolds, PsyD, based in Santa Monica, California. The website focuses on anxiety, trauma, burnout, and perfectionism, with support for in-person therapy and California telehealth.

## Live Website

🌐 **Live Demo:** https://maya-reynolds-therapy-site.netlify.app/

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React

## Deployment

The project is deployed using Netlify.
